## Motivation and changes

Consolidate **40 diffusion kernel families** optimized with **KDA-1.5 + Codex CLI + Kimi K3 on NVIDIA H200** into one PR. The changes improve tiling, vectorized data movement, parameter reuse, prefetching, launch configuration, and selected small-operation fusion across normalization/modulation, RoPE/QKV packing, VAE layout operations, linear attention/state preparation, routing, and quantization.

Production source: `620955f604199168eff2abdc8f8c198061fe2cec`, compared with baseline `c842d32b0ab45753178c5f6420662d7812766aca`. **39 production files change; existing repository tests are unchanged.** The `kernel-design-agents` coauthor is retained. This supersedes the separate Hunyuan QKV/RoPE PR #41300.

**Coverage snapshot:** further optimization and model coverage are paused at the author's request. This PR contains independently qualified kernel implementations and the completed **25 model/quality lanes across 20 models** below. Model rows name the exact source snapshot tested; older rows are not presented as full validation of this final head. Pending isolated candidates are excluded.

The native column includes only shapes/layouts captured from actual models, with regenerated values. Neither column measures full-model speed. ## Full-model benchmarks and actual outputs

Two independent **A–B–B–A groups**, eight full saved requests per row, using the same pinned model/request and GPU configuration in both arms. Timing includes the saved request; profiling runs are separate. All listed eight-output comparisons are **file-byte and decoded-pixel exact**. The original full images/videos and the eight-run audit are linked in each row. Previews are actual generated outputs: image contact sheets show **before above / after below**; animated video comparisons show **before left / after right**.

**SANA-Video is the repeated material E2E win:** lossless latency falls **2.42% / 2.44%**, and high quality **2.58% / 3.01%**. Other completed lanes do not improve by at least 1.5% in both groups; flat results and regressions are included. These are combined-change results, not attribution to a single kernel.

## Validation conditions and limitations

- Kernel frozen correctness checks pass in all three runs per family. Relevant existing tests and additional external offset/stride/dtype, nondefault-stream, changed-input CUDA Graph, multi-device and large-index checks were run as applicable; no repository test files were added or edited. Detailed counts and exceptions are in the validation report.
- NCHW GroupNorm uses the earlier original-budget constant-spatial candidate (~1.0064×). The former ~1.17× candidate failed a real Hunyuan input and is excluded; both Hunyuan quality lanes pass with the replacement.
- MXFP8's installed FlashInfer 0.6.18 GPU reference is unsupported on SM90: the same four reference tests fail in both arms, and sentinel probes show no output writes. Independent CPU quantization references and expanded production checks pass. No MXFP8 model-level speedup is claimed.
- ERNIE's existing model-fast-path tests fail in both arms. Its full-model row uses identical validation-only prompt-enhancer RNG seed/restore conditions. Helios similarly uses a symmetric CPU RNG condition; GLM uses symmetric validation-only RHS clones for the installed Torch overlap behavior.
- LTX-2 and LTX-2.3 use identical validation-only deterministic cuDNN audio-decode contexts with TF32 disabled in both arms, then restore the flags. These changes are outside the production PR. Their profile records retain unrelated SLA capture-hook installation errors; direct device events establish the changed LTX branches.
- FastH3, MiniMax-H3 and VDN-H3 retain the original warmup-off requests. Configured schedule points correspond to 4/49/8 actual denoise updates respectively. H3 multi-GPU requests use four H200s and Ulysses4.
- Final-head model coverage is incomplete. LTX-2.5 decoder, Ideogram valid-scene A/B and remaining coverage are paused. Ideogram's earlier identical safety-placeholder images are excluded. SLA, the later FP8 LayerNorm upgrade, ordinary complex RoPE and Wan timestep slices remain outside this PR pending their decisions. No claim is made that every possible diffusion kernel/model has been completed.
